# Calc+ 🧮

> **Calculadora inteligente con control de gastos, lista de compra y más.**
> Funciona **100% sin internet** · PWA instalable · Sin rastreadores · Código abierto

## ✨ Novedades v1.1

- 📋 **Historial de listas** — guarda y carga listas anteriores

- 🏷️ Total del carro siempre visible en el topbar

## Instalación rápida

```bash
git clone https://github.com/tu-usuario/calcplus.git
cd calcplus
npx serve .
```

Luego abre `http://localhost:8080`
